# Cấu hình dùng chung

Trong triển khai, đặt các tham số dữ liệu, split, seed, feature sets, model và ngân sách cảnh báo ở đây để notebook và script dùng chung. Không lưu mật khẩu/token thật. Kết nối đọc từ biến môi trường; cấu hình dịch vụ nằm tại infra/.

Seed chính dự kiến là 42. Tỷ lệ chia tập, feature và ngân sách phải thống nhất với docs/DATA_CONTRACT.md trước khi sinh kết quả so sánh. Hiện chưa có file cấu hình thực thi.
