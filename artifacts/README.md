# Kết quả chạy

- models/: mô hình đã fit và metadata cần thiết.
- scores/: điểm/dự đoán theo reading và model run.
- metrics/: kết quả ngân sách, bảng thí nghiệm và phân tích lỗi.

Các file runtime ở ba thư mục này được bỏ qua bởi Git; chúng được tạo lại bằng pipeline và giữ local để kiểm chứng. Đầu ra nào cần bàn giao sẽ xuất có chọn lọc sang reports/tables/ hoặc gói nộp theo hướng dẫn.
